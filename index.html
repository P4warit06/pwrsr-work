ตั้งค่า

ข้อมูลนี้เก็บไว้แค่ในเบราว์เซอร์ของเครื่องนี้ ไม่ถูกส่งไปที่ไหนนอกจาก api.github.com

วิธีสร้าง token (ทำครั้งเดียว)
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → เลือก hub repo และทุก repo ที่จะให้ agent ทำงาน
  3. Permissions: Issues: Read and write, Pull requests: Read, Actions: Read, Contents: Read
  4. ตั้งวันหมดอายุ (เช่น 90 วัน) แล้วคัดลอก token มาวางที่นี่

token นี้ใช้แค่ในหน้าเว็บ ส่วนการ push ไป repo อื่นใช้ secret AGENT_GH_TOKEN ของ hub แยกต่างหาก
